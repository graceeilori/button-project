# A Family of Buttons

An interactive solar system visualization that represents our group as planets — exploring personalities, interests, and the connections that bring us together.

## Check It Out

Link to the application: https://cpsc-button-project.vercel.app/

OR

Change the directory:

```bash
cd my-app
```

Install dependencies:

```bash
npm install
```

Then run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to explore.

## Features

- **Interactive Planets** — Click on any planet to explore a group members personality traits and interests
- **Comparison Mode** — Select multiple planets to discover shared interests between group members
- **Keyboard Navigation** — Easter eggs (find them!)

## Tech Stack

- **Framework**: [Next.js 14](https://nextjs.org)
- **Language**: TypeScript
- **Styling**: CSS
